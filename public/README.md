# 📂 Public Assets Directory (`/public`)

This directory contains static assets, 3D character models, and saved configuration files served at the application root.

## 📄 Files & Assets Summary

| File | Type | Description |
|---|---|---|
| [`T-Pose.fbx`](./T-Pose.fbx) | 3D Model (`.fbx`) | Rigged Mixamo FBX 3D human mannequin model used by `HumanModelManager` (`src/components/humanModel.js`) to visualize skeletal kinematics in real-time. |
| [`boneMapping.json`](./boneMapping.json) | Configuration (`.json`) | Persistent default mapping configuration establishing relationships between physical IMU sensor IDs (e.g., `Sensor1`) and Mixamo skeleton bones (e.g., `RightForeArm`). |
